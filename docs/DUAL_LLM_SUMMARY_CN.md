# 双 LLM 角色配置功能 - 实现总结

## 项目概述

为 Qinyuan Agent 工作台前端添加了**双 LLM 角色配置**功能，支持外层规划模型（Outer Role）和内层执行模型（Inner Role）的独立配置，提升任务执行的质量和准确性。

## 核心功能

### 1. 双角色架构
- **外层角色（Outer Role）**: 负责高层决策、任务规划和结果审查
- **内层角色（Inner Role）**: 负责工具调用、代码执行和观察记录
- **协同机制**: 外层制定计划，内层执行操作，外层验证结果

### 2. 用户界面
- **模式切换**: 单模型模式 ⇄ 双 LLM 角色模式
- **角色卡片**: 视觉化展示两个角色的区别和关系
- **信息提示**: 清晰说明双模型架构的优势
- **响应式设计**: 适配桌面、平板、手机

### 3. 后端支持
- **API 扩展**: `/api/model` 端点支持双模型配置
- **向后兼容**: 保持对单模型配置的完全支持
- **状态管理**: 正确跟踪和报告配置状态

## 使用方法

### 配置双 LLM
1. 打开工作台，点击左侧"模型配置"
2. 点击"双 LLM 角色模式"按钮
3. 阅读信息横幅了解架构
4. 在"Outer Role"卡片填写外层模型名称（如 `deepseek-chat`）
5. 在"Inner Role"卡片填写内层模型名称（如 `deepseek-chat`）
6. 填写共享 API Key
7. 点击"应用双角色配置"
8. 等待确认通知

### API 请求示例

**单模型配置（传统方式）**:
```json
PUT /api/model
{
  "provider": "deepseek",
  "model": "deepseek-chat",
  "base_url": "https://api.deepseek.com",
  "api_key": "sk-..."
}
```

**双 LLM 配置（新方式）**:
```json
PUT /api/model
{
  "outer_model": "deepseek-chat",
  "inner_model": "deepseek-chat",
  "api_key": "sk-..."
}
```

**状态查询**:
```json
GET /api/model
Response:
{
  "provider": "deepseek",
  "model": "deepseek-chat",
  "base_url": "https://api.deepseek.com",
  "key_configured": true,
  "protocol_version": 3,
  "dual_llm_enabled": true,
  "outer_model": "deepseek-chat",
  "inner_model": "deepseek-chat"
}
```
